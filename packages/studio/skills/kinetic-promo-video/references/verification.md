# Verification and delivery

1. `npm run check` (pinned HyperFrames 0.8.36) must finish. Review warnings; never hide real collisions using scene-wide exemptions. `qa/build.json` gives starts, durations, sample times and typography sizes.
2. When useful before a long render: `npx --yes hyperframes@0.8.36 snapshot . --at <comma-separated-times> --no-end`. Inspect pixels, not only DOM. Use native browser/computer-use for spatial acceptance.
3. `npm run render -- --output renders/final.mp4` uses bundled render.py: one HyperFrames worker, then source-audio mux with verified AAC settings and unchanged video. It refuses to overwrite an existing export; version filenames. Run `python3 verify.py . renders/final.mp4`. This probes duration/resolution/fps, fully decodes, measures actual input loudness, hashes, extracts encoded frames and creates a phone contact sheet with UI exclusion tint. It packages source and checks ZIP CRC. Requires ffmpeg/ffprobe and Pillow; if needed: `uv run --with pillow python verify.py . renders/final.mp4`. The loudnorm log's output_* fields describe a hypothetical processed signal; actual delivered measurements are input_*.
4. Inspect `qa/phone-contact-sheet.jpg`. For native moving review run `python3 review.py . --movie renders/final.mp4 --port 3033`, then open its printed localhost URL in the existing native browser profile. It provides 360×640 playback, scene jumps, and a safe-zone toggle. Check every headline, alpha/crop, CTA hold and a transition. Tint exists only in QA; faces/essential copy must remain clear. Pause/close the owned tab and stop this server afterwards. A contact sheet's existence isn't visual acceptance.
5. Audio metrics detect clipping, not musical taste. Listen through a supported path when available; otherwise deliver playable sound and disclose that independent listening wasn't possible.
6. Deliver MP4 + `renders/editable.zip`, concise checks/limitations and update the same handoff. Stop owned playback and close owned temporary tabs. A local export isn't a post.

Verifier writes `visual_review: pending`, `listening_review: not_claimed`; store actual review separately after viewing. For an audio-only revision, stream-copy the accepted video and compare elementary video hashes; don't repeat unchanged pixel QA. For visual edits inspect affected frames and boundaries. Preserve old masters.

Audio-only command: `python3 render.py . --video renders/accepted.mp4 --output renders/new-music.mp4`. Use only when the accepted visuals match this brief; the helper checks duration/dimensions and preserves the source file, then verifies unchanged elementary video bytes.
