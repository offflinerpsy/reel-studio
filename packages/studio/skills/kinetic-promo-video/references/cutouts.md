# Separate illustrations

Use the current image tool and skill; reuse accepted matching media. Don't promise a model version absent from tool provenance.

Prompt pattern:
> One isolated [subject] as a tactile editorial paper collage. Cut cream stock, visible cut/torn edges, restrained [palette] accents, overlapping pieces and a soft close shadow. Bold silhouette readable on a phone. Transparent background, complete object inside frame, breathing room, no backdrop/framing square. No tiny type or invented testimonials. [Only necessary short wordmark; exact editorial text is added locally.] Original graphic, coherent materials and lighting across this set.

Generate independently animatable objects separately (review card and one star, not a whole slide). Save images, prompt, tool receipt/output path and alpha inspection in the project. Inspect transparency on light and dark backgrounds; a dark tool preview alone doesn't prove a halo. Background removal uses the actual image editing tool, preserving supplied face/expression. Another client's portrait is never a default.

Review/answer/map motifs are illustrative. Real quotes, ratings, results and product UI require verified supplied evidence. A generated five-star card is not proof of an actual customer's rating or Google/ChatGPT endorsement. Local type is better for exact copy.

Use `kind:cutout`, `asset:assets/object.png`, short title. For custom multi-object/star animation, extend a versioned project using its deterministic scene timeline; don't rebuild unaffected scenes.
