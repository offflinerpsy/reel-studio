# Paper worlds science recipe

A reusable design recipe for a short science explanation, adapted from the owner's V5 paper-worlds template instructions. The owner-authored recipe is covered by the repository's [MIT License](../../LICENSE).

[recipe.json](recipe.json) describes visual, editorial and review constraints. It is **not an executable composition**, an importable Studio production profile or a copy of a finished film. No renderer, images, audio, approved CTA recording, fonts or private production kit is included. V5 identifies the design source; it is not a claim that this public example has a verified render or matches a private film.

## Use the recipe

1. Choose one factual question and check primary sources for its explanation.
2. Use the recipe as an authoring brief in your own composition. Create topic-specific foreground objects and a new causal timeline; changing only a title or hero image is insufficient.
3. Add your own licensed assets, narration and closing invitation. Keep the explanation and diagrams readable at phone size.
4. Render and review the actual video using the checks in the recipe before approving it for a specific destination.

For an example with a bundled builder and documented commands, start with [Kinetic Promo](../kinetic-promo/README.md) or [Portfolio Showreel](../portfolio-showreel/README.md). This recipe supplies no additional build command or service configuration.

External assets retain their own terms. Manrope is a typography reference, not a bundled font grant; obtain the font and retain its license if you use it. Publication permission, account configuration and scheduling are outside this recipe.
