# Showcase media

These original assets show Reel Studio's shared 0.4.1 interface in an isolated
preview library. Projects, briefs and the typography sample are fictional.
There are no personal finished films, account identities or connected providers
in the captures. This tour demonstrates the interface; it is not a recording of
live AI generation, remote production or an installed host qualification test.

| Asset | Purpose |
| --- | --- |
| [Short preview](reel-studio-demo.gif) | A 4.8-second, single-play introduction to the library, formats and brief. |
| [Full walkthrough](reel-studio-demo.mp4) | A silent 16.8-second tour, also showing connection settings and saved-version review. |
| [Static overview](reel-studio-overview.png) | A still image for readers who prefer a static view. |

The README uses a `picture` source for reduced-motion preferences, with an
explicit static-image link as a fallback. The MP4 has no embedded autoplay
instruction; playback depends on the viewer that opens it. All essential
instructions and product limits are also available as text outside the images.

The wordmarks, navigation images and presentation frame are original project
artwork. The interface and typography sample were captured from project-owned
source rather than borrowed from another product.

When updating the tour, use an isolated preview with fictional data, inspect
every frame, keep the short preview finite, and check the actual GitHub rendering
at ordinary and narrow widths. Update the exact path and SHA256 entries in
`scripts/public-content.mjs` only after reviewing the replacement media. Other
personal or unreviewed media must continue to fail the public-content gate.
