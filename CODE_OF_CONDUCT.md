# Code of Conduct

Help make this project a respectful place to work. Be considerate, discuss ideas and behavior rather than attacking people, and accept constructive feedback. Harassment, discrimination, threats, unwanted sexual attention, and publishing another person's private information without permission are not acceptable.

Maintainers may remove content, close discussions or restrict participation when necessary to protect the community. Report concerns privately to a maintainer through an available private channel. Share only the information needed to describe the concern; maintainers should handle reports with discretion.
